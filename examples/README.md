# Примеры пакетов

Каждый подкаталог — полный пакет участка (`site_pack.json`), схемы в `figures/` и полный
набор воды в `water.geojson`. В `site_pack.json` остаются только значимые объекты: реки до
3 км, водоёмы и скрытая вода до 1 км, слияния. Остальное — в GeoJSON, на него ссылается
`files.water_geojson`, контрольная сумма лежит в `files.sha256`.

| Пример | Ориентация | Источник оси | Что показывает |
|---|---|---|---|
| `london-city` | 135° (ЮВ) | **модель, low**: спина к главной возвышенности мезо-охвата, фасад — в противоположную сторону | город без замера компасом: как выглядит пакет по умолчанию |
| `london-city-compass` | 180° (Ю) | **замер, high**: азимут задан вручную (`--facing 180`) **для демонстрации**, а не измерен компасом | как выглядит пакет, когда ось известна точно |

**Про год карты.** `chart_year.value: 2018` в обоих примерах — условный год постройки,
взятый для демонстрации (`source: user`). Это не дата постройки конкретного здания: карта
звёзд по нему относится к периоду 8, тогда как текущий период — 9 (2024–2043). Если год
не важен, пакет собирается без `--year`, и тогда карта считается на текущий период
с пометкой «год постройки не задан».

Правило из плана: для города без компаса ось считается по модели с уверенностью `low`, и
карту летящих звёзд по такой оси нельзя считать окончательной. Пример `london-city` собран
именно так; `london-city-compass` существует только чтобы показать разницу и **не является
результатом измерения**.
