примеров и журнала → правило для старых пакетов. Ошибка без теста не считается исправленной.

- Доказательство: замер упирался в предел 3 км с обеих сторон, затем делился на 4 км.
- Нашёл: ревью ТЗ (W1). Исправлено: `0e34ad1`, версия `water 4.0.0`.
- Тест: `tests/test_water.py::test_mouth_flat_plane_is_null`, `test_mouth_v_valley_high_closure`.

## E-008 — слияние Волги и Оки не находится

- Место: `tests/golden/nizhny-novgorod-strelka`, `water[].confluences`.
- Было: 0 слияний у Волги и Оки. Ожидалось: слияние у Стрелки (карта, устье Оки).
- Доказательство: минимальное расстояние между найденными кусками русла в выгрузке — 5031 м;
  куски заканчиваются раньше устья, поэтому пересечения отрезков нет.
- Нашёл: эталонный тест (проверка факта из expect.yaml).
- Причина: `way(around:8 км)` отдаёт только куски внутри круга; устье Оки нарисовано узлом на
  члене отношения Волги, которого в выборке не было. Плюс словарь слияний был ключом по имени
  реки, и из нескольких кусков одной реки в нём оставался один.
- Исправлено: `water 6.1.0` — куски рек тянутся из отношений OSM (`rel → way(r.r)`), ключ
  слияний — `uid` куска, слияния сводятся к реке по имени. Правило: `docs/calc/rivers.md`.
- Тест: эталон `nizhny-novgorod-strelka` (статус `xfail` снят), `test_confluence_found_on_second_chunk_of_same_river`,
  `test_relation_ways_take_name_from_relation`.

## E-009 — уверенность и правило течения теряются при сборке пакета

- Место: `water_pack.to_objects`, поля `water_mouth.closure_confidence`, `enclosure`,
  `width_capped`, `capped_sides`, `closure_reason`, а также `flow_rule`, `flow_confidence`,
  `flow_chosen` у водотока.
- Было: в пакете нет ни `closure_confidence`, ни `flow_confidence`; `width_capped` = false и
  `capped_sides` = 0 всегда, потому что это дефолты модели, а не измерение.
  `landform` подставлял «medium» по умолчанию, и врата не попадали в оговорки.
- Доказательство: `WaterMouth(...)` в `water_pack.py` собирается из пяти полей вручную,
  остальные отбрасываются; то же с `WaterObject` — `flow_rule`/`flow_confidence` не передаются.
- Нашёл: ревью ТЗ R1. Исправлено: см. коммит `water: уверенность врат + I-10`.
- Тест: `tests/test_pack.py::test_mouth_confidence_reaches_pack`,
  `tests/test_validate.py::test_i10_requires_confidence_pair`.

## E-011 — нарезка окна сдвигала узлы, слияние Флит × Темза пропадало

- Место: `water.measure_water`, нарезка склеенной линии окном `max(1.5·R, 12 км)`; пример Лондона.
- Было: в пакете 63 слияния, записи Флит × Темза нет, хотя устье Флита — вершина Темзы и
  `expect.yaml` заявляет `confluences_min: 1`.
- Доказательство: кусок линии пересчитывался UTM → градусы; вершина устья сдвигалась на 9.3e-10 м,
  пересечение сегментов давало `t = -9.03e-12` и отбрасывалось условием `0 ≤ t ≤ 1`; правило
  «общий узел» сравнивает только концы линий, а устье — внутренняя вершина.
- Нашёл: внешняя проверка ZCode (T2). Исправлено в `water 6.3.2`: нарезка по диапазонам индексов,
  координаты берутся из исходной линии.
- Эталон это не ловил: фикстура Лондона без членов отношений, линия Темзы не удлиняется и не режется.
- Тест: `test_clip_runs_keep_original_vertices`; в примере — 64 слияния и запись `osm-fleet-river`
  в 603.1 м у обеих рек.

## E-013 — два предиката «скрыт» расходились на двух тегах

- Место: `water.is_hidden` (хардкод) и `hydronym.is_hidden` (конфиг `hidden_tags`).
- Было: `covered=culvert` считался скрытым для вида, но не для доли скрытого; `tunnel=yes` —
  наоборот. Линия, целиком помеченная `covered=culvert`, получала `kind: culvert` и
  `visible: true` одновременно.
- Доказательство: два независимых списка тегов.
- Нашёл: внешняя проверка ZCode (T4). Исправлено в `water 6.3.2`: одно правило — `hidden_tags`
  (`tunnel: [culvert, yes]`, `covered: [yes, culvert]`, `location: [underground]`), оба
  потребителя зовут его.
- Тест: `test_hidden_predicates_agree_on_both_tag_spellings`.
