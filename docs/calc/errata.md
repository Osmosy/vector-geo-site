# Errata: найденные ошибки расчёта

Порядок из ТЗ Б5: запись → тест-воспроизведение → исправление → проверка охвата → обновление
примеров и журнала → правило для старых пакетов. Ошибка без теста не считается исправленной.

## E-001 — closure_index 0.0 на плоской котловине

- Место: `water[].water_mouth.closure_index`, Лондон, Сити.
- Было: `0.0` при ширине 4850 м. Ожидалось: `null` с причиной «плоская долина».
- Доказательство: замер упирался в предел 3 км с обеих сторон, затем делился на 4 км.
- Нашёл: ревью ТЗ (W1). Исправлено: `0e34ad1`, версия `water 4.0.0`.
- Тест: `tests/test_water.py::test_mouth_flat_plane_is_null`, `test_mouth_v_valley_high_closure`.

## E-002 — петля у обычного изгиба

- Место: `water[].loop`, Лондон, Сити.
- Было: петля с разрывом 1090 м при длине 1510 м. Ожидалось: изгиб (`bend_kind: bend`).
- Доказательство: отношение длины к разрыву 1.38 — это излучина, а не остров.
- Нашёл: ревью ТЗ (W2). Исправлено: `0e34ad1`.
- Тест: `test_loop_absent_on_gentle_sine`, эталон `london-city` (loop: absent).

## E-008 — слияние Волги и Оки не находится

- Место: `tests/golden/nizhny-novgorod-strelka`, `water[].confluences`.
- Было: 0 слияний у Волги и Оки. Ожидалось: слияние у Стрелки (карта, устье Оки).
- Доказательство: минимальное расстояние между найденными кусками русла в выгрузке — 5031 м;
  куски заканчиваются раньше устья, поэтому пересечения отрезков нет.
- Нашёл: эталонный тест (проверка факта из expect.yaml). Статус: **не исправлено**, тест `xfail`.
- Что нужно: достраивать русло по непрерывности (гидросеть HydroRIVERS) или считать слияние
  по совпадению узлов OSM (`node(w)`), а не по пересечению ломаных.
