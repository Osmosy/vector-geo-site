# Водные врата: как считается closure_index

Формула и пороги зафиксированы здесь, чтобы поле нельзя было «подкрутить» незаметно (ТЗ W1).

1. Из точки выхода воды (`water_mouth`) проводится профиль поперёк течения, шаг 50 м,
   до 3 км в каждую сторону.
2. **Ширина долины** — расстояние до подъёма борта на 20 м. Если борт не поднялся за 3 км,
   сторона считается упёршейся в предел: `capped_sides += 1`, ширина = 3 км.
3. **Высота борта** — максимум превышения над водой по всему профилю до конца замера,
   а не значение в последней точке.
4. `enclosure = mean(left_hill_m, right_hill_m) / (width_m / 2)` — уклон бортов.
5. `closure_index = enclosure / (1 + enclosure)` — монотонно в [0, 1): 0 — борта ниже воды,
   1 — отвесные стены.
6. Если `capped_sides == 2`: `closure_index = null`, `closure_reason = "flat_valley"` —
   в плоской котловине число было бы следствием предела замера, а не свойством места (П1, П2).
7. `closure_confidence`: `low` при любом упоре, `high` при `enclosure ≥ 0.2`, иначе `medium`.
   В городской застройке DSM даёт крыши вместо бортов — уверенность не выше `medium` (П7).

Проверки: V-долина со склонами 30° → 0.97; плоскость → null/flat_valley; Лондон → 0.01
с уверенностью `low` (одна сторона упёрлась), `width_capped: true`.
