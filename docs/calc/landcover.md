# Покров: ESA WorldCover 10 м (W2)

Зачем второй источник. Вода по OSM — чужая разметка: где-то реку нарисовали осевой, где-то
забыли пруд, где-то выгрузка старая. WorldCover даёт независимый ответ по снимкам Sentinel
2021 года. Расхождение — не «ошибка», а повод записать причину; калибровка печатается одной
командой (`scripts/calibrate_water_share.py`, таблица — `water_share_calibration.md`).

## Источник

| Что | Значение |
|---|---|
| продукт | ESA WorldCover 2021 v200 |
| разрешение | 10 м |
| тайлы | 3° × 3°, EPSG:4326, имя — юго-западный угол (`N51W003`) |
| лицензия | CC BY 4.0 |
| доступ | AWS Open Data, COG: `esa-worldcover.s3.eu-central-1.amazonaws.com` |
| атрибуция | «ESA WorldCover project 2021 / Contains modified Copernicus Sentinel data (2021) processed by ESA WorldCover consortium» |

Тайл целиком — 100 МБ, поэтому читается окном (16 км вокруг участка) и кешируется вырезкой в
`~/.cache/vector-geo-site/worldcover`. Офлайн без кеша — `land_cover` кроме воды пуст и в
`quality.warnings` стоит строка `worldcover: слоя покрова нет`: «не смотрели» не выдаётся за
«воды нет».

## Классы

10 дерево · 20 кустарник · 30 трава · 40 посевы · 50 застройка · 60 голая земля · 70 снег ·
80 вода · 90 болото · 95 мангры · 100 мох.

Группы в пакете: `tree` = 10, `built` = 50, `open` = 20/30/40/60/70/100, `water` = **только 80**.
Болото и мангры в долю воды не идут: иначе расхождение с OSM объяснялось бы своей же ошибкой.

## Что попадает в пакет

`land_cover` — кольцо 0.5–2 км (то же, что у OSM-воды, иначе сравнение бессмысленно):

| Поле | Смысл |
|---|---|
| `water` | доля воды по OSM-полигонам |
| `water_wc` | доля воды по WorldCover |
| `built`, `tree`, `open` | доли групп по WorldCover |
| `source` | `ESA WorldCover 2021 v200` |
| `ring_km` | `[0.5, 2.0]` |

По клиньям того же кольца W3/W4 пишут в сектора `water_share_osm`, `water_share_wc`,
`water_share` (выбранное), `water_share_confidence`, `water_share_reason`; правило выбора —
в `water_share_rule` и в [water_share.md](water_share.md#калибровка-с-worldcover-w3-w4).

`files.land_cover` — источник, лицензия, разрешение, тайл, признак `cached`.
`attribution` — строка ESA добавляется только если слой действительно считан.

## Лондон, Сити (water 8.0.0, pack 2.2.0)

| Показатель | Значение |
|---|---|
| застройка | 81.7 % |
| дерево | 10.9 % |
| вода по OSM | 7.88 % |
| вода по снимкам | 6.96 % |
| открытое | 0.5 % |

Кольцо целиком расходится на 0.92 п.п. — внутри допуска W3 (1 п.п.). В клиньях у Темзы
расхождение больше: 申 +6.9 п.п., 辰 +10.1 п.п., 坤 +5.9 п.п. Причина видна по данным:
полигон OSM включает причалы и отливную осушку (Темза приливная), на снимке эти полосы
попадают в застройку или голую землю. Это W3/PR 5 — с причиной, порогами и `I-14`.

## Ограничения

- снимки 2021 года: новостройки и намыв после 2021 в слое отсутствуют;
- 10 м на пиксель: ручей шириной 3 м не виден вовсе, канал 8–12 м — частично;
- город: тени высоких зданий местами читаются как вода (тёмные пиксели), а тёмные крыши — как
  голая земля;
- приливная зона: осушка попадает в «голую землю», хотя в OSM это поверхность воды;
- болото (90) отдельно от воды: в поймах доля воды по снимкам ниже, чем «мокрая» площадь.

## Сверка

`python scripts/calibrate_water_share.py` — таблица по эталонам: кольца 0.5–2 и 2–8 км плюс
клинья, где расхождение больше 0.5 п.п. `--write` обновляет
`docs/calc/water_share_calibration.md`. Считается по фикстурам, без сети.
