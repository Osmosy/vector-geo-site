# Калибровка доли воды: OSM против WorldCover

Считается `python scripts/calibrate_water_share.py --write` по фикстурам эталонов,
без сети. Доли — по кольцам 0.5–2 и 2–8 км и по клиньям (24 горы).

Допуски W3: кольцо целиком ≤ 1 п.п., клин ≤ 3 п.п.
Расхождение сверх допуска — не ошибка сама по себе: у него должна быть причина.

Правило выбора: основа — OSM; WorldCover заменяет её, когда OSM воды почти не видит (osm < 0.5 % или меньше четверти показанного снимком при wc ≥ 1 %); при прочих расхождениях остаётся OSM с понижением уверенности и причиной.
