# Море в кольце: как оно определяется (E-038, S2)

## Зачем это понадобилось

До 2.13.0 море в пакете определялось одной строкой: `sea_in_ring = coast_m <= 2000`, где
`coast_m` — расстояние до `natural=coastline` в OSM. У Сувы и Сиднея это давало `false`
при том, что снимок показывал 62.9 % и 24 % воды в кольце 8 км: береговая линия у приморских
городов часто нарисована не линией, а полигонами залива, либо лежит дальше ближнего кольца.
Эталоны закрепили `false` как ожидаемый ответ — то есть зафиксировали особенность разметки OSM,
а не факт местности. Для фэншуй это ошибка: гавань и океан — главная вода перед участком (明堂).

## Признаки

Каждый признак пишется в `sea.evidence[]` с числами и источником.

| Признак | Что проверяется | Источник |
|---|---|---|
| `coastline` | `natural=coastline` в круге 8 км, расстояние по геометрии отрезков | OSM |
| `coastline_wide` | береговая линия в расширенном круге до 15 км | OSM |
| `polygon` | площадь воды с признаком моря: `natural=bay`, `water=bay\|lagoon\|harbour`, `place=sea\|ocean`, `seamark:*` | OSM, в пакете `kind: sea` |
| `tidal` | приливная вода (`tidal=yes`), только если берег в 15 км — иначе приливная река в глубине материка давала бы море | OSM |
| `satellite` | доля воды WorldCover (класс 80) или постоянной воды JRC GSW ≥ 30 % | ESA WorldCover, JRC GSW |

Порог 30 % выбран так, чтобы обычный пруд или река в кольце 8 км его не достигали: у Лондона
снимок даёт 6.9 %, у Каира 4.4 %. Море в кольце 8 км даёт десятки процентов (Сува 62.9 %).

## Правила согласия

1. Есть любой признак OSM (`coastline`, `polygon`, `tidal`) → `present: true`.
   Уверенность `high`, если ближайший признак в пределах 2 км, иначе `medium`.
2. Признак только `coastline_wide` (море есть, но берег дальше 8 км) → `present: true`,
   `confidence: medium`.
3. OSM молчит, а снимок показывает ≥ 30 % постоянной воды → **`present: null`**,
   `confidence: low`, предупреждение `sea_conflict`. Тихо писать `false` в таком случае нельзя:
   это выдаёт отсутствие признака за отсутствие моря.
4. Ничего нет и снимок ниже порога → `present: false`, `confidence: medium`.

Вид моря (`sea.kind`): `harbour` → `lagoon` → `bay` → `estuary` → `ocean` по старшинству тегов.
Слово «Port» в имени гаванью не считается: Port Jackson и Port Phillip — заливы.

Старое поле `sea_in_ring` осталось производным (`present and nearest_m <= 2000`) с пометкой
`deprecated`, чтобы старые пакеты и навыки не сломались.

## Поле в пакете

```json
"sea": {
  "present": true,
  "kind": "bay",
  "kind_ru": "залив",
  "nearest_m": 666.5,
  "sectors": ["庚"],
  "confidence": "high",
  "evidence": [
    {"kind": "polygon", "sea_kind": "bay", "name": "Port Jackson", "distance_m": 666.5,
     "area_m2": 38882806, "source": "OSM natural=bay / water=bay|lagoon|harbour / place=sea"},
    {"kind": "satellite", "share": 0.2398, "threshold": 0.3,
     "source": "ESA WorldCover класс 80 / JRC GSW permanent"}
  ],
  "note": null,
  "radius_km": 8.0,
  "deprecated_sea_in_ring": true
}
```

| Точка | `present` | Вид | Ближайший признак | Признаки |

| Сува | true | океан | 603 м (берег 8 км) | берег, прилив, снимок |
| Сидней | true | залив | 666 м (Port Jackson) | берег, полигоны заливов, прилив |
| Рио-де-Жанейро | true | залив | 432 м (берег Гуанабары) | берег, полигон |
| Гонконг | true | залив | 560 м | берег, бухты и typhoon shelters |
| Сингапур | true | океан | 8 969 м | берег 15 км (`coastline_wide`) |
| Буэнос-Айрес | true | океан | 1 865 м (Ла-Плата) | берег |
| Стамбул | true | залив | 585 м (Босфор, Золотой Рог) | берег, полигон |
| Каир | false | — | — | снимок 4.4 %, OSM молчит |
| Пекин | false | — | — | снимок 4.3 %, OSM молчит |
| Арктика 84.3° | null | — | — | нет ни OSM, ни покрытия WorldCover |

Ошибка в запросе берега тоже нашлась: `way(around:…)["natural"="coastline"]` у Сувы на 8 км
давал 0 элементов при 18 повторных — пустой ответ одного зеркала Overpass принимался за факт
местности. Теперь при нуле элементов по берегу пакет пишет `sea.evidence` без `coastline`
и опирается на остальные признаки, а не делает вывод «моря нет».
